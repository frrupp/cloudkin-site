# cloudkin-site

The published pages for **Cloudkin**, an iOS app.

**This repository is public on purpose, and holds nothing else.** The app's source
lives in a separate private repository. A page that has to be served publicly should
live somewhere that cannot accidentally serve anything private alongside it. There is
no build step and no configuration that could widen what is published — the
repository *is* the website.

Served by GitHub Pages from the `main` branch, root. Plain files: no Jekyll, no font
host, no CDN, no analytics.
